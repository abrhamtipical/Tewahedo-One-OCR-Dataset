ግዕዝ: ገተ ። ፈጻሚተ ፡ መፍቅድ ፡ ማርያም ፡ እስእለኪ ' ስእለተ ። ፀግው ኒ ፡ እግዝእትየ ፡ ለዓለመ ፡ ዓለም ፡ ሕይወተ ፡ እም ፡ እደ ፡ እኩያን ፡ አጽራርየ ፡ አድኅነኒ ፡ ሊተ ። ቅድመ፡ ሥእልከ,፡ እሰግድ ፡ ወለሥእለ 'ወልድኪ' እገኒ ። ማርያም ፡ ድንግል ፡ ማርያም : እመ ፡ አዶኒ ። ማዕበለ ፡ ጌጋይ ፡ ዕኑዕ ፡ እስመ ፡ ለአስጥሞ ፡ በጽሐኒ ። ሐመርየኒ፡ ማዕዶትየኒ፡ ሃይማኖትየኒ። ማርያም፡ ዘእንበለኪ' አልብየ ፡ ምንትኒ ። ሰላም : ለሥእልኪ ፡ ዘይኤድም ፡ ለንፃሬ ። ዓዲ ፡ ሰላም ፡ ለሥእለ ፡ወልድኪ : በኁባሬ ። አክሊለ ፡ ሢመቱ፡ ለጴጥሮስ ፡ ማርያም ፡ ዘትጸድሊ፡ እምወራውሬ ። ለተአምርኪ ፡ ባቍዕ ፡ ሶበ ፡ አቄርብ ፡ ዝማሬ ፡ ክድንኒ ፡ ሊተ ፡ ለገብርኪ ፡ ሣህለኪ ፡ ጶዴሬ ። ሰላም : ለሥእልኪ ፡ መዓዛ፡ ቅዳሴ ፡ ዘቦቱ ፡ ወለሥእለ ፡ ወልድኪ ፡ ሰላም ፡ ዘያስተፌሥሕ ፡ ሥነ፡ ርእየቱ ። ለሐዋርያ ፡ እንድርያስ፡ ቀዳማዊ ' ማርያም ፡ ሃይማኖቱ ፡ ናሁ ፡ ገደፍኩ ፡ ሕይወትየ ፡ ቅድመ ፡ ተአምርኪ ፡ ዝንቱ፡ ዓለሙኒ ፡ ኀላፊ ፡ንብረቱኒ ፡ ኀላፊ ፡ እስመ ፡ ኵሉ ፡ ኅላፊ ፡ ፡ እቱ ። ሰላም : ለሥእልኪ ፡ ዘክንፈ፡ መላእክት፡ ምጽላሉ ። ወፀዳለ ፤ ክርስቶስ ፡ ሥነ ፡ ፀዳሉ ። እመ ፡ ያዕቆብ ፡ በፀጋ ፡ ማርያም : እግዝእተ ፡ ኵሉ ። ናሁ ' አግብርትኪ ፡ በቃለ ፡ ማኅሌት ፡ይብሉ ። ስብሐት ፡ ወክብር ፡ ወሰጊድ ፡ ለመንግሥትኪ ፡ ይደሉ ። ማርያም ፡ በረክትኪ ፡ ምስሌነ ፡ የሃሉ ። ሰላም : ለሥእልኪ ፡ ወለሥእለ ፡ ወልድኪ - ዘሰዓሞ። ዮሐንስ ፡ርሔ ፡ ዮሐንስ ' ቀናንሞ ። ለዝ 'ወልድኪ ፤ መሐሪ ፡ ኅሩመ ፡ በቀል ፡ ወተቀይሞ ▪ ማርያም : በእዴኪ ፡ ሀበኒ ፡ እንዘ ፡ ትጼውዒ ፡ ስሞ ፡ ሥጋሁ ፡ ቅዱሰ ' ወክቡረ፡ደሞ ። ሰላም : ለሥእልኪ ፡ ሀፈ' ማኅየዌ ፡ በጼዴንያ ፡ ወኢትዮጵያ ፡ ዘአውኀዘት ፡ በኤሕላዌ ፡ ለመጽብሐዊ ' ማቴዎ ፡ ማርያም : እንተ ፡ ረሰይኪዮ ፡ ወንጌላዌ ። ይኩነነ ፡ ወትረ ፡ ጸሎትኪ ፡ እምዘመነ፡ ኵሉ ፡ ም'ንሳዌ ። ዓቃቤ ' ዘመዓልት ፡ ወዘሌሊት፡ ሀላዌ ። ሰላም ፡ ለሥእልኪ ፡ ሶበ ፡ ጸለየት ፡ ማርታ ። ዘአጽነነት ፡ ርእሳ ፡ ከመ ፡ ትትመጠው ፡ ስእለታ ። ምክሐ ' ታዴዎስ ፡ አንቲ ፡ ማርያም : ወሞገሰ ' ቶማስ ' ስመ ፡ መንታ። አመኢታድኅን፡ እም ፡ ወለታ ። ወአመ፡ ታገብዕ ፡ ምድር ፡ ዘነሥአት ፡ማሕፀንታ ። ኩንኒ' አንቲ ' ለመዋቲ ፡ ሐገፋ፡ ወልታ ። ሰጊድ ፡ ወአምኃ ፡ ይደሉ ፡ ለሥእልኪ ። ወለሥእለ ' ክርስቶስ ፡ ወልድኪ። ወይነ ፡ በርተሎሜዎስ ፡ አንቲ' ማርያም፡ ዘያሥተፌሥሕ ፡ ጣዕመ ' ፍቅርኪ ። አንብርኒ'

አማርኛ: ሆን ፡ በሰማዕቱ ፡ በጊዮርጊስ' ልመና፡አቤቱ፡ይቅር፡በለን። እንደ ፡ ዖፍ ፡ ክንፍ ' ያወጣ ፡ የብዙ ፡ አባት ፡ በሚሆን ፡ በአባታችን፡ በተክለ ፡ ሃይማኖት ፡ ልመና፡ አቤቱ፡ ይቅር ፡ በለን ። የዚህ ፡ ዓለም ፡ እድፍ ፡ ጉድፍ ፡ ያልነካው ፡ የገዳም ፡ ኮከብ በሚሆን፡ በአባታትን ፡ በገብረ ፡ መንፈስ ፡ ቅዱስ ፡ ልመና፡አቤቱ፡ይቅር፡በለን። እንደ፡መላእክት' ተግቶ ፡ የሚኖር፡ የሃይማኖት፡ ምሰሶ፡ በሚሆን ' በአባታችን ፡ በኢየሱስ ፡ ሞዓ፡ ልመና ፡ አቤቱ፡ ያቅር ፡ በለን ። የቤተ ክርስቲያን ፡ በገና ፡ የሆነ ፡ ነገሩ ፡ በተወደደ ፡ ባካህን ፡ ያሬድ ፡ ልመና ፡ አቤቱ ፡ ይቅር ' በለን » እመቤታችንን ፡ በወለዱ ፡ ስማቸው ፡ በከበረ ፡ በኢያቄምና ፡ በሐና ፤ ልመና : አቤቱ ፡ ይቅር ፡ በለን ፡ በአባታችን ፡ በበጸሎተ ፡ ሚካኤል ፡ እንደ ፡መላእክት ፡ በጸናች' በድካሙ ፡ ሥራና ፡ በፍጹም ፡ ልመናው ፡ አቤቱ፡ ይቅር፡ በለን ። በከበረች ቤተ ክርስቲያን፡ አንድነት ፡ በተሰበሰቡ ፡ በከበሩ፡በአባቶቻችን ፡ ሁሉ ፡ ልመና፡አቤቱ፡ይቅር፡በለን። ኣቤቱ ማረን » አቤቱ ' እዘንልን ። አቤቱ ፡ ጠብቀን ። አቤቱ ፡ አደራ ፡ በለን ። ለወገኖችህ ፡ አንድነትን ' ስጠን ። የከበረች ፡ ቤተ ፡ ክርስቲያንን ' ለማገልገል ። እግዚኦ፣ መሐረነ ፡ ክርስቶስ ' ፲፪ ጊዜ ፡ በል ። አቡነ ፡ ዘበሰማያት ፡ በል ። ቅድመ ዓለም፡ የነበርክ' ዓለምን ፡ አሳልፈህ ' የምትኖር ፡ ዛሬ ፡ እኔ ' ባርያኽን ' ታሰናብተኛለህ ።

ግዕዝ: ከመ ፡ ትክሥት፡ ብርሃነ ፡ ለአሕዛብ ፡ ሃሴ ፡ ሉያ ሃሌ ፡ ሉያ ፡ ሃሌ ፡ ሉያ አድኅነኒ ፡ በየማንከ ። ወክብረ: ለሕዝብከ ፡ እስራኤል ፡ ሃሌ ሎያ ፡ ሃሌ ፡ ሉያ ፡ ሃሌ' ሉያ ፡ አድኅነኒ ፡ በየማንከ ። ስብሐት ለአብ፡ወወልድ፡ ወመንፈስ ፡ ቅዱስ ፡ ሃሌ ፡ ሉያ ፡ ሃሌ ሉያ ፡ አድኅነኒ ፡ በየማንከ ። ለዓለም ፡ ወለዓለመ ፡ ዓለም ፡ ሃሌ ፡ ሉያ 'ሃሌ ፡ ሉያ ፡ ሃሌ ፡ ሉያ ፡ አድኅነኒ ፡ በየማንስ ። ዘአስተዳሎከ : ቅድመ ፡ ኵሉ ፡ ሕዝብከ፡ ሃሌ ሎያ፡ ሃሌ' ሉያ ፡ ሃሌ ፡ ሉያ : አድኅነኒ ፡ በየማንከ ። ጳውሎስ ፡ በል ፡ ኦ ነቅዓ ፡ ጥበብ ፡ ልሳነ ፡ ዕፍረት ፡ ጳውሎስ ' አስተምህር ፡ ለነ፡ ሰአልናከ ፡ ሃሌ ፡ ሉያ ' ሃሌ ' ሉያ ፡ ሃሌ ሉያ፡ ከመ ፡ ንትሉ፡ ንሕነ' አሠረ፡ ትምህርትከ ፡ ወንርከብ ፡ መክፈልተ፡ውስተ፡ርስትከ ፡ ሐዋ፡ ጴጥሮስ ' በል ። ዘርእስከ ፡ መልዕልተ ፡ ኵሎሙ ፡ ቅዱሳን ፡ ጴጥሮስ፡ ክቡር፡መክብበ ፡ ክርስቲያን፡ ሃሌ ፡ ሉያ ፡ ሃሌ ፡ ሉያ ፡ ሃሌ' ሉያ ፡ ባርክ ፡ ማኅበረነ ፡ በሢመተ ፡ እዴከ ፡ ወንቁም፡ ድርገተ ፡ ዘምስሌከ ።
