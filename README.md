# Tewahedo One OCR Dataset

A dataset of scanned Ethiopian Orthodox church books and documents converted into OCR text for accessibility, searchability, and digital use.

## Overview
This repository contains OCR-processed text derived from scanned documents and books related to the Ethiopian Orthodox tradition. The goal is to make church materials easier to search, preserve, and use in digital applications and study.

## Purpose
The main goal is to provide text versions of scanned church materials where only image or PDF copies were previously available. Converting these resources into plain text helps with:
- research
- digital preservation
- accessibility
- church education
- use in applications such as Tewahedo One

## Source
The source documents are scanned materials obtained and got approval from:
https://www.ethiopianorthodox.org/

## OCR and Processing
OCR work has been prepared by Abraham Sisay. The project focuses on creating text versions from scanned documents to improve access and usability.
